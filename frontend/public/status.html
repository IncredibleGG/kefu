本轮交付

近程功能:把差距补上

依测试指出的「值得补的近程功能」,四项对标 LiveChat 的核心能力已建置、部署、实测。

◆ ChatBot 事件接线 新

  • ↳流程 builder 接上入站事件:session_start / keyword / message 命中即自动跑流程并接管,可转人。
  • ↳命中则跳过 RAG 避免双重回覆;无流程的租户零回归。

◆ 公司 (Company) 一等实体 新

  • ↳公司主档 + 联系人归属,打开 B2B;新增 /company 导航与管理页。
  • ↳取代先前只能靠 attributes.company 字符串的做法。

◆ 富讯息轮播卡片 (Carousel) 新

  • ↳meta.cards 多卡横向轮播:坐席端构建器、widget scroll-snap、单卡兼容。
  • ↳补齐先前唯一 missing 的富讯息类型。

◆ SLA 营业时间感知 新

  • ↳到期只累计营业时段、跨夜与周末自动跳过。
  • ↳无设定 / 24×7 / 无效时区三层退回连续计时,零回归。
