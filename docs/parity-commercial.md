# 競品落差審計:商業 SaaS(Intercom/Zendesk/Crisp/Tidio/LiveChat/HelpScout)

判讀:我方 AI/RAG/翻譯/多租戶已達或超部分競品;落差集中在「主動經營 + 自動化引擎 + 協作」。
最高槓桿:通用「條件→動作」規則引擎(SLA/時間自動化/自動標籤/主動觸發/升級共用底層)。

## 與「基礎完善」相關的 P0/P1(這輪要做)
- 巨集/罐頭回覆(變數 + 回覆+改狀態+標籤複合)  ← 兩報告都 P0
- 私密內部備註(客戶不可見)+ 會話層標籤          ← 兩報告都 P0
- pre-chat 表單 + 離線訊息 + widget 外觀客製(租戶級)
- AI 摘要 + AI 自動分類/標籤(順勢擴充現有 gpt-5.5,低成本)
- CSAT 自動後續(結案自動發,低分開跟進工單)
- @提及 + 通知體系

## 進階/企業級(歸「之後再加」,這輪不做,只列 roadmap)
- 主動式訊息/觸發彈出、在線訪客即時清單、站內公告 banner、campaign 序列
- 通用自動化規則引擎(Triggers)、時間型自動化、視覺化 Flow
- SLA 政策 + 自動升級 + 營業時間排班
- Email 渠道完整化(IMAP/SMTP)、WhatsApp/Messenger/IG、語音
- 對外公開 Help Center、Webhook + 公開 REST API + key 管理
- 聯絡人/工單自訂欄位、side conversations、行動 App/PWA、自訂儀表板
