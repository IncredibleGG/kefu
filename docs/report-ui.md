# 客服系統 UI/UX 調研報告:tgo × cskefu 介面盤點 + 新系統 UI 架構建議

> 用途:為「全新客服系統(乾淨室重寫)」提供介面設計依據。集 tgo(AI 優先、現代 React)與 cskefu 春松客服(真人客服全套、功能成熟)兩家之長。
> 紀律:僅描述佈局與體驗,產出為**我方自有 UI 規格**。不複製任一方原始碼/圖片資產,不沿用其品牌名 / Logo / 配色。
> 調研方法:直接審閱兩套本地原始碼(tgo-web 為 React 19 + Tailwind v4;cskefu contact-center 為 Spring Boot + Pug 模板 + layui)。日期 2026-09-23。

## 0. 技術/世代速覽(影響 UI 風格的根因)

| 面向 | **tgo**(tgo-web) | **cskefu**(contact-center) |
|---|---|---|
| 前端棧 | React 19 + React Router + Tailwind v4 + Zustand + i18next,Vite | 伺服器端 Pug 模板 + layui + jQuery + KindEditor + zTree,多 iframe |
| 渲染 | SPA、前後端分離、WebSocket 即時 | 伺服器渲染頁 + iframe 嵌套 + `top.layer` 彈窗、AJAX 局部刷新 |
| 主題 | Inter 字體,亮/暗雙主題,毛玻璃、細自動隱藏捲軸 | 微軟雅黑/宋體,單亮色,layui 綠系 |
| 導覽 | 左側極窄圖示欄(64px,僅 icon) | 頂欄 + 左側樹狀選單,資訊密度高 |
| 世代印象 | 2025 現代 SaaS,留白多、圓角扁平 | 2018 傳統後台/話務台,表格重、按鈕多 |
| i18n | 完整多語(zh/en,數千鍵) | 中文為主 |

一句話:**tgo 現代但功能面淺、cskefu 功能深但介面舊**。新系統要「tgo 的殼 + cskefu 的骨」。

## 1. 畫面 / 資訊架構盤點

### 1.1 tgo(AI 優先,坐席 + AI 混合工作台)
**頂層導覽(左側圖示欄 6 項,依角色過濾)**:對話 `/chat`(三欄式核心)、AI 功能 `/ai`(Agents/Tools/Skills/Device Control/Workflows 視覺化畫布)、訪客 `/visitors`、知識庫 `/knowledge`(檔案/網站爬取/QA 三型)、接入平台 `/platforms`(admin)、設定 `/settings`(個人/通用/通知/員工/模型供應商/外掛/關於)。
**其他**:登入註冊、**Setup Wizard 安裝精靈**(管理員→坐席→LLM→驗證)、Onboarding 引導、工作流編輯器。
**渠道覆蓋(極廣)**:網頁掛件、微信/企微、WhatsApp、Telegram、Email、SMS、Facebook、Instagram、X、LinkedIn、Discord、Slack、Teams、電話、抖音/TikTok、釘釘/飛書機器人、自訂渠道。
**對話工作台 = 三欄**:左 ChatList(Tabs 我的/未分配/在線、搜尋、渠道圖示、標籤、未讀、連線狀態);中 ChatWindow(訊息流支援 Markdown/富卡片 jsonRender/圖片/emoji、**AI 回覆建議 ReplySuggestions**);右 VisitorPanel(**可拖曳 280–600px 預設 320**、訪客檔案、AI 洞察、軌跡、persona、自訂屬性、標籤)。
**widget**:獨立 React app(Header/MessageList/MessageInput/ImagePreview/Markdown/jsonRender),支援 Markdown 與富卡片;另有 Flutter/iOS/小程序/CLI 多端。
**風格**:現代 SaaS、留白、毛玻璃、藍點綴、亮/暗主題;缺點是資訊密度低、部分後台頁僅 `ComingSoonPage` 佔位。

### 1.2 cskefu(真人客服 + 呼叫中心,功能成熟)
分**坐席工作台(apps/\*)**與**管理後台(admin/\*)**兩群,頂欄切換 + 左樹狀選單。
**坐席/服務模組**:current 當前會話、**quene 排隊(可轉接)**、**online 在線監控+軌跡 trace**、history 歷史、processed 已處理/工單、comment 留言評價、leavemsg 留言、**stats 統計報表(諮詢量/滿意度/綜合)**;聯繫人/客戶 CRM;多渠道對話模板(webim/messenger/phone 呼入呼出/skype)。
**管理後台**:智能對話機器人(對接 Chatopera 雲 FAQ)、網頁客服配置(掛件外觀/邀請對話/隱藏規則)、組織架構與技能組、坐席/用戶、**角色權限(RBAC 成熟)**、渠道、簡訊、郵件、系統設定。
**風格**:傳統話務台,綠系,表格按鈕密集,layui;**功能覆蓋極完整**(排隊/質檢標註/監控/轉接/工單/報表/滿意度),但視覺舊、iframe 架構、KindEditor 笨重。

## 2. 兩家 UI 優缺點對比(擇要)
- **視覺現代感/上手引導/富文本輸入/知識庫 UX/AI 原生/渠道廣度/可維護性 → tgo 勝**。
- **排隊·在線監控·質檢標註·轉接·工單·報表統計·RBAC/組織架構/技能組·電話話務 → cskefu 勝**(tgo 這些多為佔位或缺)。
- **坐席對話台**:取 **tgo 介面 + cskefu 功能**。
- 結論:**視覺與互動框架照 tgo,功能深度照 cskefu**。

## 3. 新系統 UI 架構建議

### 設計原則
AI 原生 + 真人無縫接管;現代克制、亮暗雙主題;**資訊密度可調(坐席台提供緊湊模式)**;鍵盤優先;單一設計系統(棄 iframe 碎片化)。

### 資訊架構(導覽樹)— 窄圖示主欄 + 展開式二級側欄
```
◉ 工作台      對話工作台(三欄)· 我的 · 未分配 · 排隊 · 在線訪客監控
◉ 訪客/CRM    訪客名單 · 客戶檔案 · 聯繫人 · 標籤分群 · 軌跡
◉ AI          AI 代理 · 工具 · 技能 · 工作流(畫布)· 對話測試
◉ 知識庫      列表(檔案/網站/QA)· 匯入 · 命中分析
◉ 渠道        網頁掛件 · Telegram · WhatsApp · 微信/企微 · Email · Slack/Discord… · 電話(選配)
◉ 報表        會話量 · 坐席績效 · 排隊/等待 · 滿意度 · 質檢
◉ 設定        個人 · 團隊/坐席 · 組織架構 · 角色權限(RBAC)· 技能組 · 模型供應商 · 通知 · 外掛 · 品牌/掛件外觀
(頂欄)全域搜尋 · 坐席狀態切換(在線/忙碌/離開)· 通知 · 帳號選單
(首次)安裝精靈 + Onboarding
```
重點:報表/質檢/排隊/監控/RBAC/組織架構設為顯眼一級或二級(補 tgo 缺口);一級項目依角色動態顯示;頂欄放**坐席狀態切換**(tgo 缺)。

### 核心畫面佈局
- 對話工作台:三欄(見第 4 節)。
- 訪客/CRM:左篩選 + 右表格/卡片,點列開右側抽屜看檔案。
- AI 工作流:全幅畫布 + 左節點 palette + 右屬性面板(React Flow)。
- 知識庫:卡片列表(型別/檔數/命中率)+ 精靈式建庫。
- 後台/RBAC:左子選單 + 右表單/表格,權限用矩陣,組織用樹。
- 報表:KPI 卡片列 + 篩選 + 圖表/可匯出表格。
- 掛件:啟動氣泡 → 聊天窗(品牌/客服/線上狀態 → Markdown/富卡片/圖片/快捷按鈕 → 輸入列 → 進場前可選留言表單)+ 結束時滿意度評價,行動裝置全屏。

### 設計風格
中性灰底(Slate/Zinc)+ **自訂品牌強調色(避開 cskefu 綠與 tgo 藍)** + 語意色;亮/暗雙主題以 CSS design tokens 驅動;系統無襯線字 + 中文思源黑,等寬字用於 ID/JSON;8pt 網格、圓角 6–10px、克制陰影;WCAG AA。

### 元件庫/技術建議
- React + TypeScript + Vite(同 tgo)。
- Tailwind v4 + **shadcn/ui(Radix)為首選**(完全掌控外觀、乾淨室最安全,複製元件進自家庫無品牌綁定);密集後台頁可用 AntD 提速。
- 狀態:Zustand / Redux Toolkit + TanStack Query;即時用 WebSocket。
- 圖示 Lucide;富文本 **TipTap/ProseMirror**(取代 KindEditor);圖表 Recharts/ECharts;工作流 React Flow。
- **禁用**:iframe 拼裝、jQuery、layui。

## 4. 坐席工作台細部佈局(最核心)
**三欄 + 頂欄 + 左一級圖示主欄**;對話區彈性撐滿,兩側欄可折疊/調寬。
- **頂欄(48–56px)**:左=模組名+全域搜尋;右=**坐席狀態膠囊(在線/忙碌/離開/小休帶色點)**、當前接待量/上限、通知、聲音、帳號選單。
- **左欄 會話清單(280–320px 可折疊)**:Tabs(我的/未分配/**排隊(等待數+時長)**/在線)、搜尋+篩選(渠道/標籤/狀態);每列=頭像+**渠道角標**+名+末句預覽+時間+**未讀紅點**+標籤色條+AI/真人接管圖示+等待計時;未讀優先、上下鍵切換。
- **中欄 對話區**:
  - 標頭:訪客名+渠道+來源;操作組 **[轉接][邀請/協同][服務小結][加標籤][結束會話]** + 服務計時。
  - 訊息流:左右氣泡、系統事件置中細灰條、Markdown/**富卡片**/圖片/檔案/語音、訊息狀態(已送/已讀/失敗重送);**hover 訊息級操作**:引用/複製/**標註加旗(質檢)**/轉知識庫/翻譯;AI 接管明確標識,真人一鍵接管。
  - 輸入區:TipTap 富文本(表情/附件/插入知識庫答案/`/` 喚快捷語/滿意度);**輸入框上方 AI 回覆建議條**(合併 tgo ReplySuggestions + cskefu 知識庫聯想,一鍵採用/編輯送出);Enter 送出、Shift+Enter 換行。
- **右欄 訪客/情境面板(280–360px 可拖曳可折疊)** — Tab:①訪客資訊(檔案/來源/**關聯 CRM**/標籤/拉黑)②**AI 洞察**(意圖/情緒/摘要/建議動作/風險)③知識庫快捷(聯想一鍵插入)④歷史(過往會話)⑤**本會話搜尋+依標註過濾**。
- **空狀態/並發**:未選會話友善空狀態;多會話快速切換、新訊息左欄冒泡;近上限頂欄提示;結束彈**服務小結**(分類/備註/滿意度)沉澱進 CRM 與報表。

## 5. 一句話總結
新系統 = **tgo 的現代 React 殼、AI 原生能力與三欄工作台體驗** + **cskefu 的功能骨架(排隊/監控/質檢標註/轉接/工單/報表/RBAC/話務)**,以自有設計系統(中性灰 + 自訂品牌色、亮暗雙主題、shadcn/Tailwind)重寫,全面元件化 SPA,棄用 iframe/jQuery/layui。坐席工作台為投入重點:三欄 + AI 建議 + 可調情境面板 + 訊息級標註。
