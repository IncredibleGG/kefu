# 競品落差審計:開源客服系統(Chatwoot/FreeScout/Zammad/Rocket.Chat)

判讀:kefu 在 AI/RAG/質檢/翻譯/多租戶領先開源競品;落差集中在「坐席日常操作 + 訪客基礎體驗」的基本功。

## P0 必補(補完即與主流開源持平,前 6 項優先)
1. 罐頭訊息/快捷回覆(`/` 短碼插入,支援變數,分技能組管理)
2. 坐席對話中私密備註(內嵌 note,僅坐席可見,可 @提及)
3. 桌面/聲音通知 + 未讀徽章(web push + 聲音 + 分頁未讀數)
4. pre-chat 表單(widget 開場收姓名/email/問題,帶入 CRM)
5. 營業時間 + 離線自動回覆 + 離線留言
6. 全域搜尋(會話/訊息/聯絡人全文)
- 近 P0:轉接給指定坐席/部門(目前只轉回佇列)

## P1 重要
輸入中(typing)指示、已讀回執、會話層標籤+多維篩選、坐席 忙碌/離開 狀態聯動派單、自動輪派+坐席容量上限、巨集(macros)、SLA 計時告警、@提及團隊協作+會話協作者、資料匯出 CSV/API

## P2 加值
鍵盤快捷+命令列(⌘K)、介面多語言 i18n、會話 snooze、坐席簽名/回覆模板、陳舊會話自動化規則
